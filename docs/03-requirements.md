## 구현 상태 (GRAVIT main `6a65d1f` 기준, 2026-11-10)

위 요구사항 표의 ID마다 지금 코드가 어디까지 하는지 적는다. 요구 문장 · 중요도는 바꾸지 않고, 미구현 · 부분 구현 요구도 그대로 둔다.
