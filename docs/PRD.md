### 구현 범위 (GRAVIT main `6a65d1f` 기준, 2026-11-10)

> 판정 기준: 코드 · 테스트(프론트 `frontend/src` · 백엔드 `backend/src` · Flyway `V1`\~`V5` · E2E · 통합 테스트)를 읽어 판정했다. 닫힌 이슈 · 머지된 PR만으로 "구현"이라 하지 않았다. **미구현 · 부분 구현을 보류나 범위 제외로 확정하지 않았다** — 그 판단은 「열린 질문」에 남겼다.

| 상태 | 뜻 |
| --- | --- |
| 구현 | 화면에서 쓸 수 있고 서버(`?source=api`)까지 연결됨 |
| 부분 구현 | 일부만 동작 — 빠진 부분을 함께 적음 |
| API만 | 서버 엔드포인트는 있으나 화면에서 부르는 길이 없음 |
| 미구현 | 코드 없음(또는 계약 필드만 있고 서버가 늘 빈 값) |
| 확인 필요 | 정적으로 확인하지 못함 · 정의서 원문이 없어 비교 기준 없음 |

### 목표

1. PR, 이슈, 도움 요청, 배운 점 공유, 기타 무엇이든 회의실 안건으로 올려 함께 토론하는 과정을 3D 사무실에서 보이게 해서 배움의 흐름을 만든다 (F9 · F5).
2. 팀 레포 하나를 사무실로 보여주고, 요구사항을 구역으로 나눠 명세 → 이슈 → PR 사슬을 한눈에 보이게 한다 (F3 · F4).
3. 활동량이 아니라 막힘, 대기, 편중을 보여줘서 도움이 필요한 사람을 먼저 드러낸다 (F6 — 2026-11-10 현재 막힘 · 리뷰 대기는 구현, 편중은 미구현).
4. 코드 밖의 기여까지 포함해 개인 회고 리포트로 정리한다. 면접 꼬리질문 연습은 후순위로 둔다 (F11 · F8).
5. 강사는 모든 것을 보되, 학생이 도움을 요청한 곳(도움 요청 · 회의 결정 · 기술 결정 카드)에서만 돕게 한다 (F12 — 2026-10-30 결정).

## 3. 발표 포인트

> 기획안 「기대 효과 및 향후 확장」의 발표 포인트를 옮겼다. 1 · 2 · 6의 평가 · 회의실 안건 · 학습 타임라인은 2026-10-28에 채택됐고, 5의 "코드 밖 기여는 팀원 확인으로 기록"(FR-ACT)도 추가 결정으로 채택됐다. 3은 2026-10-30 결정으로 2번 뒤에 더했다.

1. 부캠에서는 PR을 두고 의견을 나누고 토론하는 과정 자체가 학습이라는 관점에서 출발한 LMS라는 점
2. 누구나 무엇이든 회의실 안건으로 올려, 팀이 함께 토론하며 배우는 구조
3. 강사는 모든 것을 보되 학생이 요청한 곳에서만 돕는 구조
4. 팀의 작성 방식을 바꾸지 않고 GitHub를 그대로 읽는 구조 (CON-01, CON-02)
5. 점수 대신 흐름을 보여주고, 코드 밖 기여는 팀원 확인으로 기록하는 설계와 그 이유
6. 우리 조가 직접 시범 운영한 데이터와 각자의 학습 타임라인, 회고 리포트로 시연

### 시연 순서

> 구현된 기능만으로 짰다(GRAVIT main `6a65d1f`). 미구현 기능(이슈로 만들기 링크 · 연결 후보 승인 · 편중 뷰 등)은 넣지 않았다. 실제 서버 흐름은 아직 사람이 눌러 확인하지 않았으므로 리허설에서 단계마다 확인한다. 실행 순서의 기준은 GRAVIT `README.md` 「처음 실행하기」다.

**준비 (로컬 실행 — SP11)**

1. 저장소 루트에서 `.env`를 채우고 `docker compose up -d --wait`로 MySQL을 띄운다. 심사용 시연을 하려면 `REVIEW_LOGIN_ENABLED=true`와 `REVIEW_ACCOUNTS`(레포 관리자 · 참여자 · 강사 계정)를 넣는다. 실제 GitHub 사무실을 보여 주려면 GitHub App 값을 넣는다(키 경로는 절대 경로).
2. `backend/`에서 `gradlew bootRun`(`:8080`), `frontend/`에서 `npm run dev`(`:5173`).
3. 브라우저로 `http://localhost:5173/`를 연다(`127.0.0.1`은 쓰지 않는다 — 기본이 서버 API다, GRAVIT #341). 서버 없이 화면만 보이려면 `http://localhost:5173/?source=mock`(브라우저 mock — 강사 계정이 없어 강사 흐름은 빠진다).
