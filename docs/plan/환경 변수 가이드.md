# 환경 변수 가이드

> **2026-11-03 — 실제 변수 이름의 기준은 GRAVIT [`.env.example`](https://github.com/SamdoRyu/GRAVIT/blob/main/.env.example)이다.** DB 접속은 GRAVIT의 `MYSQL_*`를 쓴다. 이 가이드의 앱 변수(`INSTRUCTOR_GITHUB_USER_IDS` · `REVIEW_LOGIN_ENABLED` · `APP_ORIGIN` · GitHub App 값 등)는 그 기능을 구현하는 GRAVIT Issue(#6 T3 · #63 IB-69 · #68 IB-06 등)에서 `.env.example`에 추가했다.

> **2026-11-07 갱신**: GRAVIT `.env.example`의 변수는 `MYSQL_DATABASE` · `MYSQL_USER` · `MYSQL_PASSWORD` · `MYSQL_ROOT_PASSWORD` · `MYSQL_PORT` · `APP_ORIGIN` · `INSTRUCTOR_GITHUB_USER_IDS` · `REVIEW_LOGIN_ENABLED` · `REVIEW_ACCOUNTS` · `GITHUB_APP_CLIENT_ID` · `GITHUB_APP_CLIENT_SECRET` · `GITHUB_APP_SLUG` · `GITHUB_APP_ID` · `GITHUB_APP_PRIVATE_KEY_PATH` · `MASTER_ADMIN_GITHUB_LOGIN`과 Vite 셸 변수 `API_PORT`(주석)다. `application.yaml`은 `MYSQL_HOST`(기본 `localhost`)도 읽는다. 기획 때 적었던 `SESSION_SECRET` · `SYNC_INTERVAL_MINUTES` · `LOG_LEVEL`은 GRAVIT에 없다. GitHub App 키 경로 · 설정 안내는 GRAVIT #237(PR 진행 중).

> 2026-11-01 결정 반영: 백엔드는 Spring Boot(Spring Security 세션 · Spring Data JPA)로 새로 만들고, 웹 애플리케이션으로 만든다(외부 배포는 2026-11-09에 하지 않기로 했다 — SP11). 아래 「1」은 데모(Hono) 설정이라 **참고용**이다. 백엔드는 Java 21 · Gradle, DB는 MySQL 8.x로 정했다(2026-11-01 추가 결정). Spring에서 변수를 어떻게 읽을지(`application` 설정 파일 · 환경 변수 매핑)와 구체 변수 이름은 Spring Boot 골격을 만들 때 정한다. → GRAVIT에서 정했다: Spring은 `backend/`에서 실행할 때 루트 `.env`를 읽는다(`application.yaml`의 `spring.config.import: optional:file:../.env[.properties]` — 실제 환경 변수가 우선). 이름은 확정이라 아래 표의 `[제안]` 표시는 지웠다.

## 원칙

레포에는 변수 이름과 설명만 담은 `.env.example`을 커밋하고, 실제 값은 팀이 정한 비밀 공유 수단으로만 주고받습니다. 이 페이지에도 값은 적지 않습니다.

- 실제 값 파일(`.env`, `.env.local`)과 GitHub App 키 파일(`*.pem`)은 `.gitignore`에 넣습니다. 데모 저장소(`warehouseDemo_fork`)의 `.gitignore`에는 `*.local`만 있었습니다. GRAVIT `.gitignore`에는 `.env` · `.env.*` · `secrets/` · `*.pem`이 있습니다.
- 값을 이슈, PR, 댓글, 채팅, 터미널 출력에 붙이지 않습니다. 확인은 "설정됨 / 미설정"까지만 합니다.
- 빈 값(`KEY=`)은 미설정과 같습니다. 서버는 시작할 때 필수 값을 검사하고, 없으면 바로 멈춥니다(기획 때 표기). 2026-11-07 GRAVIT: DB(MySQL)에 접속하지 못하면 시작하지 않습니다(Flyway). GitHub App 값이 비어도 서버는 뜨고, GitHub 로그인은 GitHub가 거부하며 실제 사무실 동기화는 `unavailable`로 기록됩니다(`application.yaml` 주석).
- 브라우저로 나가는 변수에는 비밀 값을 넣지 않습니다. 지금 화면 코드는 환경 변수(`import.meta.env`)를 하나도 쓰지 않습니다(2026-11-07 GRAVIT `frontend/src` 확인).
- Claude Code는 `.env` 계열 파일을 읽지 못하게 막아 둡니다 (`.claude/settings.json`의 `deny`).
- 막힘 기준 시간 · 강사 지정처럼 팀이 화면에서 조정하는 값은 환경 변수가 아니라 팀 설정(`TeamSettings`)에 둡니다(강사 지정 — 2026-10-30 결정).

**`APP_ORIGIN`이 가리키는 것**

로컬 개발에서는 주소가 셋입니다. 섞지 않습니다.

| 주소 | 값 (로컬) | 무엇 |
| --- | --- | --- |
| 화면 출처 | `http://localhost:5173` | 브라우저가 여는 Vite 개발 서버. 화면은 같은 출처의 `/api/*`를 부르고 Vite가 API로 넘깁니다 |
| 로그인 콜백 | `http://localhost:5173/login/oauth2/code/github` — 화면 출처 + Spring Security 기본 콜백 경로 | GitHub가 로그인 뒤 브라우저를 돌려보내는 주소. Vite 프록시를 거쳐 Spring 서버에 닿습니다. GitHub App 설정에 이 주소를 등록합니다 |
| API 서버 | Spring `127.0.0.1:8080` (바꾸면 Vite를 띄우는 셸에서 `$env:API_PORT=…`) | 브라우저가 직접 부르지 않습니다(프록시 뒤) |

그래서 로컬의 `APP_ORIGIN`은 화면 출처(`http://localhost:5173`)로 두는 것을 권장합니다. 이전 초안의 `http://localhost:3000`은 스택 확인 전 값이라 쓰지 않습니다. 콜백은 프록시 경유로 받습니다 — GRAVIT `frontend/vite.config.ts`가 `/api` · `/oauth2` · `/login/oauth2`를 `changeOrigin: false`로 넘겨 세션 쿠키 · 리다이렉트가 화면 출처 기준이 됩니다. v1은 배포하지 않으므로(SP11 · 2026-11-09 결정) 이 로컬 값을 그대로 씁니다.

**로컬 처음 설정 (GitHub 연동 — GRAVIT)**

1. `.env.example`을 복사해 루트에 `.env`를 만듭니다(`Copy-Item .env.example .env`).
2. 연동 백엔드 담당(B)이 개발용 GitHub App을 하나 만들어 둡니다. 권한은 Metadata, Contents, Issues, Pull requests를 모두 읽기 전용으로 두고, 콜백 주소는 `APP_ORIGIN` 기준으로 등록합니다(로컬: `http://localhost:5173/login/oauth2/code/github`).
3. B가 App ID, Client ID, Client secret, 키 파일을 팀 비밀 공유 수단으로 나눠 줍니다. 키 파일은 `./secrets/`에 둡니다. 그 전에 개발 저장소의 `.gitignore`와 `.claude/settings.json`에서 이 폴더가 막혀 있는지 먼저 확인합니다(GRAVIT은 둘 다 막혀 있음).
4. 필요하면 `MASTER_ADMIN_GITHUB_LOGIN`을 넣고(선택) 서버를 띄웁니다. GitHub App 설정 안내는 GRAVIT #237(PR 진행 중)이 머지되면 GRAVIT README를 봅니다.
5. 연동 작업을 할 때만 GitHub 데이터를 씁니다.

개발용 App을 모두가 함께 쓰려면 화면 포트가 같아야 합니다. 포트가 다르면 콜백 주소가 어긋나 로그인이 실패합니다.

## .env.example

GRAVIT 루트에 있다 — [`.env.example`](https://github.com/SamdoRyu/GRAVIT/blob/main/.env.example)을 본다(변수 목록은 위 「2」). 이 문서에 있던 신규 예정 초안(`SESSION_SECRET` · `LOG_LEVEL` · `SYNC_INTERVAL_MINUTES` 포함)은 GRAVIT 파일로 대신해 지웠다(기획 저장소 git 이력에 남아 있다).

`APP_ORIGIN`, 포트처럼 비밀이 아닌 기본값만 채워 두고, 비밀 값은 비워 둡니다.
