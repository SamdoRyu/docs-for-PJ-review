## 모든 화면 공통 인수 조건

> 초안 — 기획안 디자인 원칙과 NFR에서만 만들었다. 팀이 확인하면 "초안"을 지운다. 기능별 인수 조건은 04 「인수 조건」 열.

1. 1024px 너비 노트북 · 태블릿에서 상단 바와 패널이 잘리지 않고, 상단 바와 패널은 3D 로딩이 끝나기 전에 먼저 보인다 (NFR-07, NFR-02).
2. 어느 화면에도 팀원 간 · 조 간 순위 · 비교와 사람별 합계가 없고, 개인 지표(회고 리포트 · 학습 타임라인 · 기술 결정 카드)는 본인과 강사에게만 보이며, 막힘 표시는 막혔다는 사실만 보이고 이유 문구는 없다 (FR-FLOW-06, NFR-06, FR-FLOW-02 · 2026-10-29 결정, 강사 보기 · 조 간 비교 금지는 2026-10-30 결정).

| 권한 없음 | 서버가 `forbidden_role`로 거부한다. 강사(ROLE-04)가 요청되지 않은 건에 쓰거나 허용되지 않은 쓰기를 해도 같다 — 새 에러 code는 없다(2026-10-30 결정). 들어갈 수 없는 사무실은 존재를 드러내지 않도록 `not_found`(구현 기본값 — 2026-11-01 추가 결정). 화면 문구: 구현 — 예외 처리 UI(GRAVIT #274)의 전체 화면(「이 사무실을 열 수 없어요」 · 다시 시도) · 폼 오류 · 거절 토스트로 보인다(문구는 GRAVIT `frontend/src/data/rules/errors.ts`). 화면은 강사에게 쓰기 버튼을 숨긴다 | FR-AUTH-04 · FR-AUTH-08 · P1 · P2 · P13 |
| 데이터 없음 (이슈 0개 · 명세 문서 경로 없음 등) | 기획안에 서술 없음. 구현 — 예외 처리 UI(GRAVIT #274)의 패널 상태(불러오기 실패 · 빈 상태)로 보인다. 명세 문서 경로를 건너뛴 경우 요구사항 패널은 빈 상태 문구를 보이지만, 그 문구가 안내하는 "팀 설정"은 없고 나중에 경로를 넣는 화면도 없다(FR-REQ-01 부분 구현 — 코드 쪽 문구 문제) | FR-REQ-01 |

> 구현 상태: GRAVIT main `6a65d1f` 기준 (2026-11-10). 프론트 코드(`frontend/src/ui/` · `src/scene/`)와 테스트로 판정했다 — 닫힌 이슈 · 머지된 PR로 판정하지 않는다. 위 화면 목록 · 흐름표가 요구이고, 이 절은 지금 만든 모양이다 — 다르면 요구가 기준이다. 상태 표기: **구현**(화면에서 쓸 수 있고 서버 `?source=api`까지 연결) · **부분 구현**(빠진 부분을 함께 적음) · **API만**(서버 엔드포인트만 있고 화면에서 부르는 길이 없음) · **미구현** · **확인 필요**. 기존 결정인 "v1 보류" · "[제안]"은 그대로 둔다. 이슈 번호는 근거로만 적었다. 화면은 기본으로 브라우저 mock 데이터로 뜨고, 주소에 `?source=api`를 붙이면 Spring v1 API(로그인 필요)를 쓴다 — GitHub 로그인 뒤 `?source`가 빠져도 sessionStorage로 api 모드를 유지한다. mock에는 강사 계정이 없어 강사 쓰기는 mock에서 늘 거부된다. mock 「데이터 초기화」 메뉴는 없다.

**진입 흐름**: URL 라우터 없이 상태로 화면이 바뀐다(`frontend/src/App.tsx` · `src/ui/entry/`, 주소는 `?source=api` · `?workspace=<id>`만 — `?workspace=<id>`로 그 사무실을 바로 연다). 로그인(GitHub · 접힌 심사용 폼) → 사무실 고르기(내 사무실 · 강사 요청함(강사) · 조직 · 레포 목록 · 「승인 요청하기」 — 이 브라우저에 지난번 사무실 기억이 있으면 바로 연다) → 레포 관리자가 아직 열리지 않은 레포를 고르면 사무실 열기 → 처음 한 번 **도착 장면**(행성 줌인 · 궤도 진입 연출 — 계정마다 처음 사무실을 고를 때 한 번, `gravit.landingSeen.<userId>`, 움직임 줄이기 설정이면 알림만. 최대 수 초 HUD를 덮는다) → 3D 사무실 + HUD. 다른 사무실로 가는 길은 둘이다: ① 3D **도킹 베이 우주선**을 누르면 "어느 정거장으로 갈까요?" 목록(행성 색 점 · 시연 · 역할 깃발)이 뜨고, 고르면 **워프** 연출 뒤 바로 그 사무실이 열린다(목록의 "정거장 목록 화면으로"는 사무실 고르기 화면) ② 더보기 「사무실 바꾸기」 → 사무실 고르기 화면(마지막 사무실 기억을 지움). 상단 바 레포 드롭다운은 없다(근거 GRAVIT #267 · #268 — 코드 주석 "팀 결정 2026-11-09", 결정 기록에는 없음).

**사무실 안 HUD**: 위는 상단 바, 가운데는 3D 정거장, 오른쪽은 관리 패널(위 상세 서랍 + 아래 탭 칸반 · 목록 · 주간 · 도움 요청 · 스탠드업 · 결정 기록 · 요구사항 · 회고(회고 리포트 · 학습 타임라인 · 기술 결정 카드) — 넓게/좁게 · 접기, 도움 요청 탭에는 새 강사 답변 빨간 점)이고, 나머지는 대화상자로 연다.

**상단 바 실제 구성**: GRAVIT 로고 | 저장소 이름(시연 사무실은 표시 이름) · "서버" 배지(api 모드에서 SSE 연결 시) · D-day(레포 관리자가 누르면 기간 대화상자) · 열린 PR · 평균 리뷰 대기 · 동기화 칩(누르면 수동 동기화 — 팀원만, 강사는 설명만) · 「회의」(단축키 M) · 이름 첫 글자 · 더보기. **상단 바에 없는 것**: 레포 드롭다운 · 요구사항 진행률 · "시연 데이터" 배지(시연 표시는 사무실 고르기 목록과 도킹 우주선 목록의 "시연" 깃발) · "기록되지 않은 기여는 반영되지 않습니다" 안내 · 팀 설정 버튼.
