> 우선순위 열 읽는 법: **확정**은 정의서 ID(기획안 MVP 표의 Must / Should·Could), **제안**은 requirements-changes.md의 제안 우선순위(채택 전), **채택**은 2026-10-28에 채택된 제안(제안 우선순위 그대로, 결정 기록이 바꾼 값은 그 값), **보류**는 2026-10-28에 보류된 제안(FR-FLOW-07), **원본 확인 필요**는 정의서 원문이 없어 내용을 정하지 못한 ID다. 기능 그룹이 MVP라고 해서 그 그룹의 세부 요구사항이 모두 Must인 것은 아니다.
> 인수 조건 열은 R의 수용 기준 문장(정의서 인용 문장 · requirements-changes.md 수용 기준), 05-policy.md의 P 규칙, 기획안의 해당 절에서만 만든 **초안**이다. 각 조건 끝 괄호에 실제 출처를 적었다. 원본 확인 필요 ID의 내용과 [?] 로는 조건을 만들지 않았다. [제안] 조건은 채택된 뒤에만 완료 기준이 된다. 팀이 확인하면 상태를 바꾼다.
